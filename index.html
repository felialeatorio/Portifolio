/ Sobre Mim

Com mais de 3 anos de estrada, sou um desenvolvedor apaixonado por criar arquiteturas limpas e escaláveis. Atualmente, foco em construir ecossistemas complexos usando Laravel e interfaces reativas modernas.

Minha filosofia é simples: código deve ser escrito para humanos, não apenas máquinas. Por isso, aplico rigorosamente princípios de POO, Clean Code e testes automatizados em cada entrega. Seja integrando gateways de pagamento complexos ou otimizando consultas SQL, busco sempre a performance máxima.
